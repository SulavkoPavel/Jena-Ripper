Jena Ripper — portable-версия для Windows
==========================================

Что это такое
-------------

Jena Ripper — локальный инструмент для исследования RDF-графов Apache Jena.
В архив уже включены backend, frontend и Java Runtime.

Как запустить
------------

1. Полностью распакуйте ZIP-архив в любую папку.
2. Откройте распакованную папку Jena-Ripper.
3. Дважды нажмите start.bat.
4. Дождитесь запуска приложения. Jena Ripper попытается автоматически открыть
   страницу в браузере по адресу http://127.0.0.1:<свободный порт>/.

Не запускайте start.bat несколько раз. Каждый запуск создаёт отдельный процесс.
Для Local TDB2 одновременно должен работать только один процесс, иначе Dataset
может оказаться заблокированным.

Как это работает
----------------

start.bat запускает только Java из распакованного архива:

runtime\bin\java.exe -> jena-ripper.jar

Файл jena-ripper.jar содержит:

- Spring Boot backend и REST API;
- production frontend Jena Ripper;
- Graph Explorer;
- SPARQL Console;
- Redis Console;
- Owner Rules и Redis Rules;
- настройки и профили подключений.

После запуска Spring Boot выбирает свободный локальный порт и слушает только
127.0.0.1. Доступ из внешней сети не открывается. Frontend загружается из того
же процесса и обращается к REST API через тот же адрес.

Если браузер не открылся
------------------------

Откройте файл журнала и найдите последнюю строку:

Jena Ripper started: http://127.0.0.1:xxxxx/

Скопируйте этот адрес в браузер.

Настройки и профили
-------------------

Настройки не хранятся внутри распакованного архива. Они сохраняются здесь:

%APPDATA%\jena-ripper\profiles.json

Пользовательские шаблоны и история SPARQL/Redis сохраняются отдельно:

%APPDATA%\jena-ripper\jena-ripper-user-data.json

Поэтому архив можно перемещать или заменять новой версией без потери профилей.

Логи
----

%LOCALAPPDATA%\JenaRipper\logs\jena-ripper.log

Пароли и токены специально не выводятся в журнал.

Как остановить
--------------

Для корректной остановки используйте кнопку «Выключить Jena Ripper» в правой части header.
Она штатно закрывает Spring context и освобождает Local TDB2 Dataset. Ctrl+C в окне
консоли также запускает стандартный Spring shutdown hook.
Закрытие одной вкладки браузера не завершает backend.

Важно
-----

- Не переносите отдельно start.bat или jena-ripper.jar: рядом нужна папка runtime.
- Не запускайте Local TDB2 одновременно из CIM App, dev backend и portable Jena Ripper.
- Если Dataset заблокирован, закройте остальные приложения, использующие тот же путь,
  затем перезапустите Jena Ripper один раз.
