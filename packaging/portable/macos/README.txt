Jena Ripper — portable-версия для macOS
========================================

Что это такое
-------------

Jena Ripper — локальный инструмент для исследования RDF-графов Apache Jena.
В архив уже включены backend, frontend и Java Runtime для архитектуры вашего Mac.
Устанавливать Java, Node.js, npm или Maven аналитику не требуется.

Как запустить
------------

1. Полностью распакуйте ZIP-архив.
2. Откройте распакованную папку Jena-Ripper.
3. Дважды нажмите «Jena Ripper.command».
4. Дождитесь запуска приложения. Jena Ripper попытается автоматически открыть
   страницу по адресу http://127.0.0.1:<свободный порт>/.

При первом запуске macOS может попросить подтвердить открытие загруженного
скрипта. При необходимости выберите в Finder «Открыть». Не отключайте Gatekeeper.

Не запускайте «Jena Ripper.command» несколько раз. Для Local TDB2 одновременно
должен работать только один процесс.

Как это работает
----------------

«Jena Ripper.command» запускает Java только из распакованного архива:

runtime/bin/java -> jena-ripper.jar

JAR содержит Spring Boot backend, REST API и production frontend. После запуска
выбирается свободный порт только на 127.0.0.1. Внешний сетевой доступ не открывается.

Если браузер не открылся
------------------------

Откройте журнал и найдите строку:

Jena Ripper started: http://127.0.0.1:xxxxx/

Настройки и профили
-------------------

~/Library/Application Support/JenaRipper/jena-ripper-settings.json

Пользовательские шаблоны и история SPARQL/Redis:

~/Library/Application Support/JenaRipper/jena-ripper-user-data.json

Настройки находятся вне распакованного архива, поэтому обновление portable-версии
не удаляет профили подключений.

Логи
----

~/Library/Logs/JenaRipper/jena-ripper.log

Пароли и токены в журнал не выводятся.

Как остановить
--------------

Для корректной остановки используйте кнопку «Выключить Jena Ripper» в правой части header.
Она штатно закрывает Spring context и освобождает Local TDB2 Dataset. Ctrl+C в окне
Terminal также запускает стандартный Spring shutdown hook.
Закрытие вкладки браузера не завершает backend.

Важно
-----

- Не переносите отдельно JAR или command-файл: рядом нужна папка runtime.
- Используйте архив, соответствующий архитектуре Mac: arm64 или x64.
- Не открывайте один Local TDB2 одновременно из нескольких приложений.
